
A colleague recently checked my GitHub page and as he discovered some repositories mentioning Emacs, he shouted "Hey, Anton, why are you using Emacs?! You should be using VIM!" I do use multiple code editors, and I actually use them for their separate purposes. I am using Emacs as a planning tool, specifically its very famous "org mode". So this blog post will not be about code editor wars (many of these code editors can be very powerful in the right hands), but rather how to do planning in Emacs. The idea of this blog post came to me long time ago, and I am glad I finally found time to compile all of this information together.

In fact, as many of us, I have used multiple planning tools in the past. TODO Describe what I used in the past. I switched to Emacs for planning about 3 years ago (and still keep using it) because I wanted a flexible format to represent my plans (a versioned text-based format is the best for me) and to be able to customize the planning views just as I wanted. Over these 3 years I have experimented quite a bit with Emacs configuration, and the aim of this blog post is to share what worked the best for me.
